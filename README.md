# MiniBank-ABC (Python)

MiniBank-ABC is a simple web-based banking simulator built with **Python, Flask, and SQLite**. It demonstrates fundamental software engineering concepts through basic banking operations.

### Features
- Account management and balance inquiry
- Money deposits and fund transfers
- Transaction history
- REST API integration
- Input validation and SQL injection prevention
- Database transaction integrity

### Technology Stack
- **Backend:** Python + Flask
- **Database:** SQLite
- **Frontend:** HTML + CSS
- **Communication:** HTTP / REST API

### Architecture
A simple three-layer logical architecture:
1. **Client Layer:** Web browser and API clients.
2. **Application Layer:** Flask application and business logic.
3. **Data Layer:** SQLite database.

### Learning Objectives
Explore Python development, web application architecture, database management, REST API development, functional testing, and application security.

**Note:** This project is an educational banking simulator, not a production banking system.
